No exact timing guarantee when OS denies access, after force-stop, before storage unlock or under device restrictions; no battery bypass by default, no approximate fallback for #1. Separate scheduling from hourly sync work; 7-day replenishment must be proved without app foreground. Resolve all-day next-day/missed-day edge semantics against product #23/#24 and existing schedule rules; seek owner decision if ambiguous rather than inventing policy.
- Atomic DB changes only; side effects after commit, durable idempotent reconciliation/retry with no rollback of valid business Save because provider fails. No plaintext fallback, preserve SQLCipher/Keystore, restore clears/pause device state before any reschedule, reconcile only after confirmed permission/identity. Timezone uses authoritative work zone; all-day/date-only local calendar dates, DST existing P7A policy. Use per-occurrence/day stable identity, duplicate prevention across retries/restarts/restore, careful handling of manual one-shot vs managed records.
