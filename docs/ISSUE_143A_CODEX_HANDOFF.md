### Numbering and UI

- New series use separate annual counters and `КШ` / `ЗК` with `{prefix}-{year}-{sequence}`, minimum width four. Shared mode takes the greater of the two type-specific maxima. The local issue date comes from the same timestamp as initial save. A follow-up revision uses the root number and policy.
- The grammar supports `prefix`, `year`, `yearShort`, `month`, `day` and `sequence`. It requires a prefix, exactly one year token and a sequence. The template accepts BMP Unicode letters and decimal digits, ASCII space, and `-_. /·+№()` punctuation. Prefixes accept those letters and digits and `-_`, require at least one letter or digit and are compared using locale-independent lowercase with exact code points. Output preserves accepted text and delimiters. Bounds are 96 template code units, 20 prefix code units, 91 public-number code units and sequence width 1–12.
- Preview computes both types without saving. Shared-mode previews represent alternative next issues. Allocation searches at most 64 sequential candidates under the writer lock and fails transactionally on collision or overflow. A restored image only knows reservations present in that image.
- Android settings show the standard examples and the deferred editor. Existing PDF headings use the exact public number. Filename sanitization and length limits apply to the filename separately. P6B can use the shared allocator inside its future document transaction. The full editor and profile remain in [#177](https://github.com/aleks-nl5/andrey-ceilings-android/issues/177).
