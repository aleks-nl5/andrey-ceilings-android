## 11. Draft PR review decisions

The ceiling owns one individual quote series over its lifetime. The **+** action creates v1 only if the ceiling has never had a series. With one active series it opens the existing version proposal from the latest active revision. The writer enforces the same creation rule within its transaction and preserves successful operation receipts. A proposed revision identical in document content to its base is rejected without allocating a version. A meaningful change to the title, discount, lines, omissions or frozen measurement content permits a new version.

Legacy ceilings with multiple historical series require an explicit version selection. The **+** shortcut reports that it cannot choose a series. A fully deleted series also blocks **+** while retaining its original number and history. Existing active legacy documents remain available by exact revision. Any recovery or consolidation policy for these edge cases requires an owner decision.

The normal workspace uses four outlined tabs with a receipt icon for quotes. Rounded themed headers and subtle dividers group related controls. Cost help stays with the confirmed total, placement details stay with their row, and potential totals align to the right. The quote total has stronger emphasis and omissions scroll alongside included rows. Quote trash icons use the theme’s monochrome treatment. An element row is a single visual touch surface with independently actionable icons.
