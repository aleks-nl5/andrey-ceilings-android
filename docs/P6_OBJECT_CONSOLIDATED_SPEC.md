## #143 — остаточно погоджений продуктовий контракт нумерації (25.11.2026)

Спільний шаблон за замовчуванням, опціонально окремі шаблони для individual/consolidated. **Один універсальний редактор**, не два режими: готові шаблони підставляють редагований текст; користувач може одразу змінити його.
