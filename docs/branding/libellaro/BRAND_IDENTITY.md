# Libellaro — айдентика v1.1 (25.11.2026)

## Погоджене власником
- Робоча назва: **Libellaro**, від латинського libella (будівельний рівень). Авторське слово, не латинський термін.
- Античний знак: римський будівельний рівень, висок, геометрія/перспектива стелі. Детальний основний знак; простий знак для іконок. Не додавати текст до launcher icon.
- Слоган EN: **From measurement to masterpiece.**
- Слоган UK: **Від заміру до шедевру.**
- Зберігати версії окремо за мовами, не двомовний текст у UI. Англійська/українська — ресурси, не hardcode.
- Не додавати бренд до кореневого README (головна сторінка GitHub). Назва робоча, продаж не планується; юридична доступність не підтверджена. Перед публічним поширенням перевірити ТМ, зокрема LIBELLA Hultafors.

Файлів шрифтів не додаємо. Зберігаємо чинний шрифт і тему інтерфейсу, золоті акценти декоративні, не малий неконтрастний текст.

## Ресурси та використання
- `svg/`: primary, horizontal, symbol; світлі, темні, монохромні, окремі EN/UK lockups; квадратна іконка без слогану.
- `android/res/`: вихідні Android adaptive layers і конфігурації, не інтегровані у production. Старі launcher PNG та растрові експорти підготувати з SVG під час implementation.
- Не деформувати пропорції; для PDF — монохромний горизонтальний знак лише після погодження, не заміна реквізитів майстра/компанії.
- Логотип з назвою/слоганом використовувати лише в достатньо великих місцях. Іконка, системний splash — знак без тексту. Місце слогану та compact header погодити окремо.
