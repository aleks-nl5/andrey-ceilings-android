## Обов'язкові продуктові правила

- [«Майстер насамперед»](architecture/MASTER_FIRST_UX_AND_DELIVERY.md): **контур + розміри → полотно + профіль → Save** без зайвих елементів. Далі окремо: додати роботу без кількості, уточнити кількість, розмістити, відредагувати точну геометрію.
- Базова заявлена кількість **не є** геометричною довжиною/площею; різні поля й різні стани. Перед перенесенням з креслення потрібне явне порівняння **зараз заявлено / із креслення**, потім підтвердження. Не втрачати ручне значення.
- **Небезпечні дії — ліворуч і червоним; безпечна відміна/продовження — праворуч.** Не застосовувати це до нешкідливого «Застосувати».
- Для «розмістити ще» і нового placement — **іконка чотирьох стрілок**, для створення нового елемента — окремий плюс. Поля мають бути невисокими **за рахунок внутрішніх відступів**, а не обрізання тексту. Контекстна `?` біля поля кількості, з правого боку.
- Видимість чернетки і можливість Save не є синонімами: при dirty/invalid показувати **чітку причину** і шлях усунення, не ховати попередження. Звичайне натискання Save при блокуванні не пише в БД, лише відкриває причину.

### Critical normal-mode rendering regression (owner APK, 18:51)

- **Observed:** in normal mode both contour and grid disappear, while fullscreen renders both normally; live geometry summary still shows 6.00 m² / 10.00 m.
- **Confirmed root cause:** `MeasurementEditScreen` lays out a normal-mode `Column` with Canvas `Box(weight=1f)` **and** bottom `Spacer(normalPanelHeight - tabBleed)`. A later camera change additionally passed `bottom=normalPanelHeight` to `MeasurementDrawing.viewportPadding`. Its `viewportHeight = canvasHeight - header - bottom` became zero; `Canvas` returned before **grid and contour**.
- **Fix:** only reserve the overlaid header in Canvas (`bottom=0.dp`). Panel is already reserved in layout; no changes to world-mm, geometry, database, or placement gestures.
- **Regression coverage:** Android layout test asserts **positive viewport and fitted 2×3 m contour** in normal mode, and switches normal/fullscreen; Desktop 360×580 scene asserts the same and fit on both transitions. **CI/APK on corrected SHA not yet verified.**

### Додаткові вимоги 23.11.2026 (наступний Android smoke)

- **Fullscreen:** один тап на контур/POINT/LINE/AREA лише виділяє об'єкт та рядок списку (і не відкриває sheet); подвійний тап відкриває відповідну картку параметрів; під час перетягування sheet лишається закритим. Контекстні FAB дозволяють свідоме ручне відкриття.
- **Work list:** press/ripple і виділення мають бути обрізані за 10dp rounded shape, без гострого прямокутного підсвічування на виступах.
- **Normal/fullscreen:** обидва переходи автоматично запускають вписування в **видиму** область, з урахуванням normal overlay, без зміни world-mm. Зміна вкладки сама по собі не викликає reset масштабу.
- **Локалізація:** нові підписи контекстних вкладок, кнопки «Вписати креслення» та доступне оголошення креслення винесено в Compose resources; не перекладати користувацькі назви прайсу. Решта наявних hardcoded написів потребують планового i18n-аудиту.

### Owner APK 19:02–19:04 — length field vs drawing-to-estimate transfer

- **Confirmed intent:** «Ця лінія, м» is the actual length of **one selected line**. «Усі лінії» is the sum across the same catalog work; «Для кошторису» is **declared/billable quantity**. Transferring from drawing updates ONLY the billable quantity, never a particular line's geometry.
- **Additional concrete UI defect:** the transfer dialog could be opened while `lineProperties` had an un-applied typed length. `displayLines()` rightly still used applied geometry, but the dialog looked like it was transferring the newly typed value; this mismatch confused the workflow.
- **Fix in current Draft:** three concise labels adjacent in geometry editor, moved transfer icon to the billable quantity row (away from geometry-edit toolbar), explicit before/after in dialog; transfer disabled with a specific explanation until pending geometry fields are confirmed (✓). Model refuses programmatic stale transfer too, regression JVM test added. New strings use CMP resources. **Requires latest CI + owner's APK test.**

## 2. Переогляд суміжної архітектури

**Перевірені напрями diff:** швидке створення заміру і редагування «Контур»; `WorkspaceAddDialog`, прайс/ролі полотна й профілю; `WorkspaceWorkList`; LINE/AREA/POINT geometry/model/UI/writer; `MeasurementEditStore` → `WorkspacePlacementWriter` → `CeilingEditRepository`; undo/redo/atomics/CAS; sheet/viewport/Canvas hit-testing; Android/desktop тести, ресурси й документація.

- **Модель:** точні world-mm, UUID та наявні типи геометрії залишаються source of truth; кількість для прайсу **окреме** поле work, геометрія її автоматично не перезаписує. `ElementQuantity.Unknown` дозволений для MANUAL/ENTERED_LENGTH (за чинними quantity rules), але не можна вважати Unknown числом 0/1 або самостійно міняти похідні CANVAS/PROFILE режими.
- **Store:** зміна кількості `additions.editedWorks` входить у той самий WorkspaceWriter atomic Save/CAS із геометрією. Це не змінює frozen estimates/PDF. **Реальний rollback/retry та фізичний APK перевірити на фінальному SHA**.
- **Обмеження:** після перенесення 0,899 м.п. в заявлену кількість **намальована** лінія не повинна подовжуватися понад 0,899 без окремого збільшення declared quantity. Це **обмеження місткості**, а не «неправильний формат числа». Чинні правила не змінені заднім числом.
- **Навігація:** у normal редакторі системний Back має перш за все пройти вкладені стани/каталог/розміщення/редагування, далі захищений вихід із заміру. Режим fullscreen та післязбережуваний exit не повинні губити модель.
- **Локалізація/a11y:** shared CMP resources для нових користувацьких повідомлень, не перекладати user-authored price names; усі іконки мають semantic labels. Компактне оформлення не може зменшувати hit targets нижче доступних норм.

| **AREA з креслення** | Додати обхід труби без кількості → поставити 1 фігуру → «Кількість з креслення» → змінити заявлену до 2 | Розміщено 1 шт., заявлено 2 шт.; обидві величини видно; Save/reopen. Для м² враховувати площу, для шт. — кількість фігур. |

| **Save / exit** | Змінити незастосовану довжину/кількість, отримати blocker → дискета → Back | Дискета **пояснює** blocker при tap; **жодного DB-write** при невалідному стані; вихід чесно показує незбережений draft і безпечні дії. |
| **Список/кнопки** | Перейти до вже доданої роботи, розмістити ще, відкрити параметри, змінити 2 елементи по черзі | Чотири стрілки для placement, бінокль для переходу, зрозуміле підсвічування, компактність, жодних осиротілих полів/втрати чернетки. |
