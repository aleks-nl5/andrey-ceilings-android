# Спільна локалізація L1

Українська (`uk`) доступна в режимах «Системна» та «Українська». Системний
режим використовує українську для підтримуваних українських тегів і як
fallback для решти мов. Налаштування зберігається в окремому ключі
`app_language`. Android використовує наявний файл `app_preferences`,
desktop — Java Preferences, iOS — NSUserDefaults. У Android перемикач
розміщено в наявному пункті «Мова». Desktop читає локаль процесу JVM.
iOS має адаптер для майбутнього хоста #42 та спостерігає за повідомленнями
про зміну локалі й повернення у foreground.

Спільні ресурси містять назву, підзаголовок, доступний підпис кнопки
налаштувань, параметризовану дію навігації та форми множини для кількості
об’єктів у картці клієнта. Android і Desktop використовують ті самі
компоненти CMP. Згенеровані accessors належать до `:shared`, тому
ресурсні ключі не дублюються у платформних хостах.

CMP 1.12.2 надає Compose APIs для читання рядків, однак створення
`ResourceEnvironment` і надання власного compose environment на цій
версії мають внутрішню видимість. Адаптацію цієї версії ізольовано в
`AppLanguageResources.kt`. Вона змінює мовні кваліфікатори, успадковує
тему й density, зберігає ідентичність піддерева Compose та використовує
правила множини CMP для української на пристроях з іншою системною
мовою. Оновлення CMP потребує повторної перевірки адаптера та
ресурсних тестів. Перевірено рекомендації щодо конфігурації
[ресурсів у Gradle](https://kotlinlang.org/docs/multiplatform/compose-multiplatform-resources-setup.html),
[середовища локалі](https://kotlinlang.org/docs/multiplatform/compose-resource-environment.html)
і [параметрів та множини](https://kotlinlang.org/docs/multiplatform/compose-localize-strings.html).

Вибір мови записує лише preference і не змінює глобальну локаль,
Android Configuration або AppleLanguages. Числові поля й дати
продовжують використовувати свої чинні правила. Для даних регресійний
Android тест порівнює весь початковий та власний прайс, групи, ревізії,
суми і джерела PDF до зміни мови та після перевіреного portable restore.
Межі подальшої міграції описано в [інвентарі L0](LOCALIZATION_L0_INVENTORY.md).
