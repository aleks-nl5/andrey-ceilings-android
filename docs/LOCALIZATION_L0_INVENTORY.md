`ci/localization-baseline.json` містить шлях, категорію та кількість входжень. Для
рядків, які перевіряє CI, та ресурсів звіт також містить текст. Для тестових,
доменних, технічних та інших рядків звіт зберігає зведені кількості за файлами.

```sh
python3 ci/localization.py inventory --ref 565e8ea6cc25b9abffea98ee08bde6cfece1289b --out /tmp/stelapro-l0.json
cmp ci/localization-baseline.json /tmp/stelapro-l0.json
python3 -m unittest discover -s ci/tests -p test_localization.py -v
python3 ci/localization.py check --base origin/main --head HEAD
```

У `iosApp` на вихідному SHA є лише README. iOS-адаптери й тести належать до
`shared/src/iosMain` і `shared/src/iosTest`. Сканер має окремі правила для
повідомлень Android, але на вихідному SHA не знайшов прямих літералів у
відповідних API сповіщень.

Сканер читає відстежувані Git-файли Kotlin, Java, Swift, XML, Apple Strings
і SQL. Він розпізнає прямі аргументи поширених UI-викликів, відомі імена
параметрів, кириличні рядки у файлах інтерфейсу та типові accessibility,
PDF і notification API. У PR він зіставляє кількості однакових входжень у
поточному файлі та файлі з базового коміту, з урахуванням перейменувань,
розпізнаних Git. Для початкового внесення він також звіряє весь історичний
знімок із базовим комітом. Додавання дубліката рядка з історії перевіряється
так само, як додавання нового рядка.

`StarterPriceCatalog.kt` і `PriceNameMigration.kt` обліковано як джерела
значень прайсу. Назви користувача, що надходять із БД та заморожених
кошторисів, не є вихідними літералами. SQL, wire ID, `testTag`, відомі
діагностичні виклики й тестові source sets відокремлено від перевірки UI.

Евристика не будує граф потоку даних. Рядки у непрямих англомовних
константах, вкладених виразах шаблонів і нетипових обгортках можуть
потребувати ручного огляду. Літерал у UI-виклику може бути технічним в
окремому контексті. Класифікація PDF та доменних повідомлень є орієнтиром
для міграції. Звіт рахує входження, тому повтори в коді враховано окремо.

L2 починається зі спільної навігації й оболонки, далі йдуть налаштування,
P5B та решта екранів. L3 охоплює підписи редактора прайсу й системні
підписи документів. Друга продуктова мова належить до L4.
